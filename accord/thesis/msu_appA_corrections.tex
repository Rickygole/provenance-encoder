\chapter{The Correction Record}
\label{app:corrections}

This work issued 110 distinct numbered corrections and 9 post-freeze revisions. Each withdrew, narrowed, or confirmed a claim against evidence. Correction and check identifiers begin with C and come from one shared sequence. An identifier absent from Chapter 3's table of pre-registered checks is therefore a correction entry here. The corrections are summarised instead of reprinted, because no reader reads the complete record in sequence. The full text of each is released with the analysis code, the same treatment given to the record of reported quantities and the claim-and-evidence trace.

Several changed a number this thesis prints; each is named by identifier in the released record and cross-referenced from the chapter carrying its corrected value. The most consequential is C95 (of 110), the largest single withdrawal in the record, named by identifier because the record kept growing after it. C95 withdrew every result this work obtained by sending sentence pairs to a hosted model service, following PhysioNet's guidance of 24 September 2025, whose conditions for a hosted service this project could not verify for the runs it had made (Chapter~\ref{ch:method}, Section~``\nameref{sec:m-ethics}''); the hosted routes are withdrawn, whatever an earlier draft had listed. That removed the only variation in labeller capability the design contained. Whether over-calling magnitude belongs to the pool or to the labeller is open again, and this thesis says so without returning to an attribution an earlier correction had retracted. The withdrawal is enforced by the provenance check. Withdrawn values sit in a separate part of the record, and the check will not match a printed number against that part. The previous withdrawal was enforced by prose alone, so a printed number could have matched a withdrawn value unnoticed. The record is kept so that a reader can see what was corrected and when, and it includes this project's own failures.
