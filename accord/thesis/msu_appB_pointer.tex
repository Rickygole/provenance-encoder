\section*{Reference Tables Bound in the Supplement}
\phantomsection
\addcontentsline{toc}{section}{Reference Tables Bound in the Supplement}
\label{app:provenance}

Three reference tables belong to the record behind this thesis, machine-generated
by \texttt{accord/stats/make\_appendices.py} and \texttt{accord/stats/trace\_claims.py}
and reproduced complete, without abbreviation, in the supplementary file that
accompanies this document; together they run to more than thirty pages of table,
none of which is read sequentially. The first is the register of reported
quantities: 1397 values, each extracted from a stored result file by script
rather than transcribed by hand, listed with the file it was read from. The
second is the claim and evidence trace, resolving 1152 numeric occurrences in
the chapters against the register: 283 match a single registered value, 613
match one of several candidates on sentence context, and 256 remain genuinely
ambiguous, recorded as such. The third is the survey coding table behind the
prevalence measurement in Chapter~\ref{ch:results}: all 75 coded papers,
reproduced in full so the counts can be recomputed rather than taken on trust.
