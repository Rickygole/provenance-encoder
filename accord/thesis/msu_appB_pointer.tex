\section{Reference Tables Released with the Code}
\label{app:provenance}

Two reference tables belong to the record behind this thesis, machine-generated by the appendix builder and the claim tracer in the analysis code released with this thesis. Both are released with that code rather than bound, because together they run to more than thirty pages of table, none of which is read sequentially. The first is the register of reported quantities: 5556 values, each extracted from a stored result file by script rather than transcribed by hand, listed with the file it was read from. The second is the claim and evidence trace, which scans the chapters for 1792 numeric literals and resolves 1787 of them against the register, at the precision printed: of the 844 distinct registered quantities the trace names, 306 are matched uniquely and 538 are matched among more than one candidate and marked as indicative rather than definitive. The remaining 5 literals are not resolved to any registered value and are listed as untraced rather than omitted.
