\section{Reference Tables Released with the Code}
\label{app:provenance}

Three reference tables belong to the record behind this thesis, machine-generated by the appendix builder and the claim tracer in the analysis code released with this thesis. The first two are released with that code rather than bound, because together they run to more than thirty pages of table, none of which is read sequentially. The first is the register of reported quantities: 5338 values, each extracted from a stored result file by script rather than transcribed by hand, listed with the file it was read from. The second is the claim and evidence trace, which scans the chapters for 1490 numeric literals and resolves 1485 of them against the register, at the precision printed: of the 725 distinct registered quantities the trace names, 257 are matched uniquely and 468 are matched among more than one candidate and marked as indicative rather than definitive. The remaining 5 literals are not resolved to any registered value and are listed as untraced rather than omitted. The third, the survey coding table behind the prevalence measurement in Chapter~\ref{ch:results}, is bound in the Supplement, Section S3: all 75 coded papers, reproduced in full so the counts can be recomputed rather than taken on trust.
