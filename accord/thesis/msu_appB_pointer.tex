\chapter{Reference Tables}
\label{app:provenance}
\label{app:trace}
\label{app:survey}

Three reference tables belong to the record behind this thesis. All three are
machine-generated from the project's stored results by
\texttt{accord/stats/make\_appendices.py} and
\texttt{accord/stats/trace\_claims.py}, and all three are reproduced complete,
without abbreviation, in the supplementary file that accompanies this document.
They are bound separately because together they run to more than thirty pages of
table, none of which is read sequentially, and because a table that exists to be
consulted is not made more useful by sitting between the conclusion and the back
cover.

The first is the register of reported quantities. Every number printed in this
thesis is drawn from it: 1363 values, each extracted from a stored result file by
script rather than transcribed by hand, grouped by the experiment that produced
it and listed with the file it was read from. The register is what makes the
claim in Chapter~\ref{ch:method} checkable rather than asserted, namely that
no figure in this document was typed from a draft, a note, or memory.

The second is the claim and evidence trace. It resolves all 1064 numeric
occurrences in the chapters to 412 distinct registered values, and for each one
records the sentence it supports alongside the artifact it came from. Where a
value is shared by more than one registered quantity and the surrounding sentence
does not disambiguate them, the trace says so rather than choosing silently, so
an uncertain attribution is visible as uncertain.

The third is the survey coding table. The prevalence measurement reported in
Chapter~\ref{ch:results} rests on 75 papers coded against a written instrument,
and the full coding is reproduced so that those counts can be recomputed by a
reader rather than taken on trust.

Appendix~\ref{app:corrections}, the correction record, is not in the supplement.
It is an account of what this project got wrong and when, it is written rather
than generated, and it belongs with the argument.
