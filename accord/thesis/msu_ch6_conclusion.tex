\chapter{Summary and Conclusion}
\label{ch:conclusion}

\section{What Was Asked}
\label{sec:conc-asked}

A nursing note records that a loop diuretic was held because the patient had
become hypovolemic; the discharge summary written five days later instructs
that the same drug be continued at the admission dose. Only one of those
documents leaves the hospital with the patient, and it is not the one
containing the reason the instruction is wrong.

This thesis asked whether that disagreement can be detected automatically
from paired clinical notes in MIMIC-III \citep{johnson2016mimic}, and built a
standard-shaped pipeline to answer it: rule-based candidate mining, language
model weak supervision, and a purpose-built neural detector over a
domain-pretrained clinical encoder. Five questions were posed, four about
the stages and one about the field that publishes pipelines like this one;
every stage failed a control, and Section~\ref{sec:conc-found} keeps rather
than collapses the distinction between failures that carry different
weight.

\section{What Was Found}
\label{sec:conc-found}

Chapter~\ref{ch:discussion}, Table~\ref{tab:disc-spine} synthesises what
each stage reported before its control and what the control changed; this
section states the outcome once. Every one of the five questions failed a
control. The candidate pool's enrichment is real, but its precision is
bounded above by an exemplar defect that made the evidence displayed to the
annotator, the weak labeller, and the detector independent of the evidence
that triggered the candidate. The weak labeller's marginal fixes an
agreement ceiling before training begins, and the labeller that actually
supplied the detector's training signal could not have cleared the
conventional significance threshold at any outcome its own marginal
permitted. None of three credited architectural components is left holding
what it was credited with, and the three failures are of three different
kinds. The trained detector's ranking is at chance under both evaluation
bases and under subject-disjoint splits, a result the labeller's marginal
already predicts rather than one that needed explaining after the fact, and
a TF-IDF logistic regression ranks above both neural configurations, which
is either surface-form signal or small-sample noise and is not established
either way. A $75$-paper corpus deliberately enriched toward careful work
still finds the one control this survey measures rare. Not every failure
carries the same weight, a distinction Chapter~\ref{ch:discussion} keeps
rather than collapses.

\section{What the Controls Changed}
\label{sec:conc-controls}

Without controls, everything above reads as a small underpowered study that
found nothing; the controls convert the same results into measurements with
a stated resolution. The positive control carries the most weight: adapting
one observational-epidemiology device \citep{lipsitch2010negative} by
running the analysis where the answer is known, it resolves $4.53$ accuracy
points on AG News under the identical harness, while the same harness
returns a null, $+0.0031$, on the clinical task built for this control
alone; what that pairing licenses is argued in
Section~\ref{sec:disc-null}. The general proposition
that pretraining loss predicts downstream utility poorly is established
elsewhere, at a scale this project cannot approach
\citep{lourie2025scaling,feng2026tessera}.

Decontamination changed the headline, not its usefulness: the number
reported before it was contaminated, and nothing in the metrics said so.
Sign provenance changed no value and several conclusions, reproducing every
prior figure exactly while reversing seven of fourteen comparable drift
slopes, because a quantity stored as a magnitude licenses no directional
claim. The randomisation control on the second system did not settle RQ3:
the pre-specified role-label control ran underpowered, not falsified, and
an arm showing an arbitrary ordinal outperforming true role labels is a
rival hypothesis, not a control task.

\section{Things to Check If You Are Building This}
\label{sec:conc-practice}

These are the checks that, run when they were available, would have
changed what is reported here.

Check that the evidence a candidate is displayed with is the evidence that
triggered it. The check is a one-line assertion, illustrated in
Figure~\ref{fig:exemplar}, and here it would have caught the largest
upstream defect in this project before any annotation was commissioned.
Estimate the base rate on a human-labelled sample before generating weak
labels, and print the labeller's marginal beside it; the dependence of
agreement statistics on the marginals has been documented since 1990
\citep{feinstein1990paradoxes,byrt1993pabak}. Report precision against the
pool's own base rate, with the denominator stated, and prefer a coefficient
that uses all four confusion-matrix cells when the classes are this skewed
\citep{chicco2020mcc}. Run a randomised counterpart of any component
reported as learned, under the same training conditions, and log the
distance a learned parameter moved from its initialisation. Run a positive
control on the instrument before reporting a null from it, and report
achieved power alongside any comparison that returns no difference. Keep
denominators separate and state them with every metric; conflating two of
them in this project inverted a central claim that survived several rounds
of internal review.

\section{Future Work}
\label{sec:conc-future}

Three pieces of work follow directly from the limitations, and a fourth
rejoins them where an earlier draft of this thesis reported it as already
settled. Each needs a resource this project did not have: the annotator's
time, an annotation budget, a controlled simulator, and, for the fourth, a
second model scale reachable through a channel this thesis can use
compliantly. That fourth item would order the over-calling multiplier by
parameter count; the cell an earlier draft relied on to report it came
through a hosted channel now withdrawn under the compliance action
Chapter~\ref{ch:method} records, so the question returns to future work
rather than staying answered.

\textbf{Re-annotate against corrected exemplars.} The base rate of $0.0401$
remains an upper bound rather than an estimate. By reconstruction the
exemplar matched the trigger for $72$ of the $137$ resolved Rule 1 and Rule
2 candidates, a rate of $0.5255$; by an exact join covering far fewer rows,
all $23$ of the $23$ it can resolve match. Rebuilding the selector so the
displayed pair is the pair that fired the rule, then re-annotating the same
candidate identifiers, would establish how much of the measured base rate
is real. The rules and the pool exist and the defect is located, so this is
bounded work.

\textbf{Assemble a cohort with more positives.} Every interval here rests
on $12$ positives. The minimum detectable AUROC at that count is $0.7355$
at $80\%$ power and $\alpha = 0.05$, and the smallest stratum difference
the exemplar comparison could detect is $0.0895$ in absolute rate. A
cohort large enough to resolve effects where a useful clinical system
would operate is the single change that would most alter what can be
concluded, and it means annotation budget rather than modelling effort.

\textbf{Explain the selection channel anomaly.} Two selection channels on
one population with baseline disparity held fixed produce demographic
parity drift slopes of opposite sign, $-0.0078$ and $+0.0118$, and a
controlled simulator sweep inverts rather than reproduces the mapping. The
pattern is stable, reproducible, and unexplained; five candidate mechanisms
were proposed and refuted inside this project, and the sixth is left to
work that can hold more of the generating process fixed than this design
allows.

\section{Closing}
\label{sec:conc-closing}

Dangerous medication contradictions between nursing notes and discharge summaries are real,
recurring, and worth detecting. A standard-shaped pipeline built for them does not detect them,
and the sharpest thing this thesis can say is that sentence together with the mechanism behind
it. The weak labeller assigns the contradiction class to the large majority of a pool whose
confirmed rate is a twentieth of that, and at that marginal the largest agreement any
thresholded label could express with the pharmacist is bounded before training begins. That
bound follows from two marginals alone, needing no join, no significance test, and no vendor,
which is why the detector inherits a marginal rather than a judgement. Every other failure in
this thesis is attached to a mechanism of the same kind, read out of the code or the counts
rather than inferred from a null.

None of that establishes that the task cannot be done (Section~\ref{sec:disc-null}). It
establishes that each failure has a located mechanism, separated from measurement artifact by a
control that fired, except the harm head, which needed no control because nothing ever trained it.

The practical recommendation is one sentence. Before training anything downstream of a weak
labeller for a rare clinical event, measure that labeller's positive rate against the gold
standard's confirmed rate and check what agreement its own marginal permits before spending a
training budget on the rest. This project's local evaluation baseline was such a check run late
rather than early: prompted once with no training, it returned the same null on the same rows
the finished pipeline did. Run first, it would have named the marginal ceiling this thesis
instead spent a pipeline discovering.

A negative result that has been diagnosed is worth more than one that has not. Part of that
diagnosis was a set of controls that belong to other people's papers
\citep{lipsitch2010negative,adebayo2018sanity,hewitt2019control,egami2023surrogates,feinstein1990paradoxes},
cost $1216.4$ GPU minutes in total, and had not been run on this pipeline before this work. The rest is four checks of its own: the marginal feasibility gate, trigger-exemplar
dissociation, the degeneracy precondition, and sign provenance. Each is cheap, each catches a
defect no reported metric here was sensitive to, and none is a new method.
