E7. IS THE BIAS MONOTONE IN THE STRENGTH OF X-DEPENDENCE?
==============================================================================
In the mean-preserving multiplicative family above: yes, exactly linear.
Question: is monotonicity a general property? Search a logistic family
   pi_lam(x) = sigmoid(alpha + lam * h(x))
for a counterexample where b(lam) = Cov(f,pi_lam)/E[pi_lam] is NON-monotone.
    COUNTEREXAMPLE FOUND after 2 draws. alpha = -0.007364
    b(0) = -1.110e-16 (must be 0: no X-dependence => no bias)
    |b| PEAKS at 0.061599 (b=-0.061599) at lam = 0.950,
    then DECAYS back to |b| = 0.020886 at lam = 12.0.
    So |b| is non-monotone: it rises then falls by a factor of 2.95x.
    sampled trajectory:
      lam= 0.000  b=-0.00000000
      lam= 1.200  b=-0.06018147
      lam= 2.400  b=-0.04537095
      lam= 3.600  b=-0.03711252
      lam= 4.800  b=-0.03225312
      lam= 6.000  b=-0.02874799
      lam= 7.200  b=-0.02610437
      lam= 8.400  b=-0.02413129
      lam= 9.600  b=-0.02268385
      lam=10.800  b=-0.02163651
      lam=12.000  b=-0.02088584

    => Monotonicity is NOT a general property. It holds exactly (and
       linearly) in the mean-preserving multiplicative family, because
       there the denominator E[pi] is constant in lam. Here the
       denominator moves too: as lam -> infinity, pi -> an indicator,
       and BOTH Cov and E[pi] saturate, so b can turn around.
       Substantively: the worst audit distortion occurs at MODERATE
       X-dependence, not at the most extreme.

E10. 'ONLY IF pi(x,a)=pi(a)' IS FALSE **FOR THE GAP**  (precision check)
==============================================================================
pi(x,a)=pi(a) is SUFFICIENT for per-group invariance, and per-group
invariance implies gap invariance. But the GAP can be preserved by
cancellation while BOTH groups are individually biased. Constructed:
choose group-specific lam_a so that lam_0*slope_0 = lam_1*slope_1.
    lam_0 = 0.900000, lam_1 = 0.366409  (both nonzero => pi DOES depend on X)
    per-group FPR shift: b_0 = +0.048366536521   b_1 = +0.048366536521
    |b_0 - b_1| = 0.000e+00   (they cancel)
    population FPR gap = -0.097002689474
    pool       FPR gap = -0.097002689474
    |gap difference|   = 0.000e+00

    => GAP is preserved to machine precision, yet each group's FPR is
       wrong by ~0.048 and pi is NOT of the form pi(a).
       So 'invariance holds ONLY IF pi(x,a)=pi(a)' is FALSE as stated
       for the gap. It is true for PER-GROUP invariance uniformly over f.
